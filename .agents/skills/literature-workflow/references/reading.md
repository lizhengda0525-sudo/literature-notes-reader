# 单篇阅读与续读

## 先读原文，再编排笔记

使用当前归档版本的全文。先通读摘要、引言、主要图表和结论，确认研究任务与作者声称解决的问题。再细读方法、实验和支撑核心结论的必要附录，回原文核对变量、数值、图注与限定条件。按 [appraisal.md](appraisal.md) 评价实验与适用范围。提取文本只作定位，乱码、公式和图表以实际页面为准。材料不足时说明实际阅读范围。

每篇唯一正式笔记是论文目录的 close-reading.md，使用 paper_note.md 模板。面向读者的笔记不写逐段引注、文献引用清单、页码标记、原文摘录清单或证据编号、证据表，也不另建此类记录。使用自然的中文讲解。保留必要的英文术语、图名、公式和 DOI。

## 按以下顺序组织正式笔记

1. **论文信息。** 写原文题名、中文题名、作者、期刊或会议、年份及可核实的 DOI。以实际阅读版本为准，区分在线发表与卷期年份。未报告的元信息如实说明。
2. **摘要中译。** 忠实、完整地翻译作者摘要。保留主语、条件、比较对象、数值和语气。摘要为结构化格式时保留小标题。此处只呈现作者的意思。
3. **主方法框架图。** 查看作者在正文或随文附录中呈现的方法图及图注，核实它确实展示本文采用的方法。把原图完整裁入本篇 images/，以 Markdown 图片语法和相对路径嵌入。保留分图、箭头、符号及图例；中文图注说明它们与输入、处理步骤、输出的对应关系。优先展示能够说明主方法的作者原图。不要用结果图、未来设想或别篇论文的图代替。找不到时在本节写“未找到作者提供的主方法框架图，待你决定如何处理。”并在交付或当前对话中主动提示用户。如果原文缺页或图无法辨认，说明实际原因、标记待你决定。继续翻译和精读其余内容，保持该处空缺直到用户明确决定。禁止自行绘图、生成示意图、拼造总图或以流程图代替。若用户决定略过，记为“按你的决定略过框架图”。
4. **结论中译。** 翻译作者结论章节的全部正文，保留局限及将来时表述。没有独立结论时注明选自讨论末尾的总结段。确无对应内容就说明，由精读部分承担读者分析。
5. **精读笔记。** 讲清论文针对的困难、相对已有工作的变化及其影响。方法型论文从一个输入走到输出，解释关键符号、假设、优化和推断，选真正帮助理解的例子。围绕最有辨别力的实验解释数据、基线、指标、结果及适用边界。综述或理论论文按其分类思路、命题与成立条件展开。用措辞区分作者结果、读者判断与尚待检验的假设。个人笔记置于本节末，原样保留 USER_NOTES_START/END 之间内容。
6. **与动态脑网络建模的联系。** 作为全文最后一节。联系具体设计，例如有向连接的定义、时间分辨率、采样与时滞、状态切换或评价协议。解释哪些条件需要重新检验，可提出一个能区分不同解释的对照。联系较弱就说明边界，不强行推导临床用途。尚未确认的数据模态和研究条件保持开放。

## 保存与续读

软件从同一份 Markdown 提供排版、目录与双栏编辑，PDF 在 Zotero 阅读。附件关联及个人笔记维护方式见项目 README。临时文本和渲染使用项目根目录 .tmp/，仅长期需要的插图存入论文 images/。结束后按 [commands.md](commands.md) 清理。

完整阅读、翻译和方法核查结束后才能将阅读状态记为 deep_read。已核实缺少作者图并已提示时，可完成其余阅读。速读或局部阅读最多记 skimmed。人工核对由用户决定。分段陪读时按约定粒度推进，将下次要读的问题和原文位置写入 state.md，续读前重新打开相应页面。
