# 单篇阅读与续读

## 先读原文，再编排笔记

使用当前归档版本的全文。先通读摘要、引言、主要图表和结论，确认研究任务与作者声称解决的问题。再细读方法、实验和支撑核心结论的必要附录，回原文核对变量、数值、图注与限定条件。按 [appraisal.md](appraisal.md) 评价实验与适用范围。提取文本只作定位，乱码、公式和图表以实际页面为准。材料不足时说明实际阅读范围。

每篇唯一正式笔记是论文目录的 close-reading.md，使用 paper_note.md 模板。面向读者的笔记不写逐段引注、文献引用清单、页码标记、原文摘录清单或证据编号、证据表，也不另建此类记录。使用自然的中文讲解。保留必要的英文术语、图名、公式和 DOI。

## 按以下顺序组织正式笔记

1. **论文信息。** 写原文题名、中文题名、作者、期刊或会议、年份及可核实的 DOI。以实际阅读版本为准，区分在线发表与卷期年份。未报告的元信息如实说明。
2. **摘要。** 完整翻译作者摘要。保留主语、条件、比较对象、数值、语气和结构化摘要的小标题。中文下方按模板折叠作者英文全文。保留原段落及专业术语，核对 PDF 抽取时产生的连字与行末断词。
3. **关键词。** 在摘要之后单列一节，按作者给出的顺序、大小写与拼写照录英文 Keywords 或 Index Terms。缺少时写“原文未提供英文关键词。”项目自行维护的方法标签仍用于检索。
4. **主方法框架图。** 查看作者在正文或随文附录中呈现的方法图及图注，核实它确实展示本文采用的方法。把原图完整裁入本篇 images/，以 Markdown 图片语法和相对路径嵌入。保留分图、箭头、符号及图例。中文图注说明它们与输入、处理步骤、输出的对应关系。找不到时在本节写“未找到作者提供的主方法框架图，待你决定如何处理。”并在对话中主动提示。如果原文缺页或图无法辨认，说明实际原因。继续翻译和精读其余内容，保持该处空缺直到用户明确决定。禁止绘图、生成示意图、拼造总图或用其他论文的图替代。若用户决定略过，记为“按你的决定略过框架图”。
5. **结论。** 完整翻译作者结论，再折叠对应的英文段落。保留局限、将来时表述和原段落次序。没有独立结论时，注明选用讨论末尾的总结段，并提供该段中英文。确实没有相应内容时写“原文未提供结论或讨论总结段。”缺少摘要时采用同一原则。已有可读内容、仅缺英文版本时写“原文未提供英文摘要。”或“原文未提供英文结论。”并保留能核实的内容。
6. **精读笔记。** 讲清论文针对的困难、相对已有工作的变化及其影响。方法型论文从输入讲到输出，解释关键符号、假设、优化和推断，选帮助理解的例子。围绕最有辨别力的实验解释数据、基线、指标、结果及适用边界。综述或理论论文按其分类思路、命题与成立条件展开。把相关图、表、公式链接放在实际讲到它的句子上。用措辞区分作者结果、读者判断与尚待检验的假设。个人笔记置于本节末，原样保留 USER_NOTES_START/END 之间内容。
7. **与动态脑网络建模的联系。** 作为全文最后一节。联系具体设计，例如有向连接的定义、时间分辨率、采样与时滞、状态切换或评价协议。解释哪些条件需要重新检验，可提出一个能区分不同解释的对照。联系较弱就说明边界。尚未确认的数据模态和研究条件保持开放。

## 归档用于对照的图、表和公式

逐页核查正式正文、随文附录和单独的补充文件，登记所有带编号的图、表和公式，包括精读正文没有逐项讨论的材料。以印刷标签为准，保留罗马数字、字母前缀和分式编号。一个图号下的多个面板合为一项，多个独立编号分别收录。同一页上的多个条目各裁一份可读原图，保留图例、符号、表头、脚注或整行公式。图号重复时用来源区分。多个版本重复收录同一材料时只登记一次，说明实际使用的版本与范围。

每篇论文单独保存 resources.json，顶层含 schema_version（1）、sources、items。在 sources 中逐份写入 id、label、scope（main 或 supplement）、status（available、unavailable 或 none）。归档文件的 file 是本篇目录下的 PDF 文件名，在 note 中说明来源或范围。先核查论文对补充资料的说明，已知存在而尚未取得的附件登记为 unavailable，并在交付时告知用户。只在核实作者没有补充材料时使用 none。作者稿附录和出版方单独附件分别标明实际取得情况。

items 的每项写 id、kind（figure、table、equation）、number（作者原编号）、title（中文短题名）、source（来源 id）、page（PDF 物理页，从 1 起）和 image（本篇 images/ 下的相对路径）。可用 description 解释阅读方法。id 使用小写字母、数字和连字符，建立后保留，方便现有笔记持续引用。例如将笔记中的“式 (5)”写成 `[式 (5)](#res-eq-5)`，其中 eq-5 必须是本篇已有条目。逐条核对裁图、来源、编号和清晰度，再统计各类条目。

## 保存与续读

软件从同一份 Markdown 提供排版、目录与双栏编辑，PDF 在 Zotero 阅读。附件关联及个人笔记维护方式见项目 README。临时文本和渲染使用项目根目录 .tmp/，仅长期需要的插图存入论文 images/。结束后按 [commands.md](commands.md) 清理。

完整阅读、翻译和方法核查结束后才能将阅读状态记为 deep_read。已核实缺少作者图并已提示时，可完成其余阅读。速读或局部阅读最多记 skimmed。人工核对由用户决定。分段陪读时按约定粒度推进，将下次要读的问题和原文位置写入 state.md，续读前重新打开相应页面。
