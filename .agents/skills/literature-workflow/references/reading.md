# 单篇阅读与续读

## 三遍阅读
1. 定位：核对题名与版本；阅读摘要、引言、章节、主要图表和结论。回答论文类型、背景、贡献、假设与表达清晰度，形成一句话定位。
2. 细读：重建任务定义、输入输出、真值来源、模型结构、目标函数、约束/正则、优化流程、数据处理和评价协议。记录关键术语、符号与首次位置。
3. 核查与综合：建立主要结论到证据的对应关系；检查基线、对照、消融、不确定性、适用条件和复现信息。把可复用内容连接到已确认的研究问题。

标准自主精读覆盖目标全文和支撑主要结论的必要附录；明确实际阅读范围、未读或无法核对的部分。每次关键解释前重读相关原文页，提取文本只用于定位。
可重建的提取文本、OCR 与整页渲染放 .tmp/ 下的任务子目录；extract 输出到 .tmp/extract/Pxxxx/。完成本轮记录和核查后 clean Pxxxx，其他临时内容按任务清理；续读时按需要重新生成。
只有完成上述范围、关键图表核查和模板所需笔记后，才执行 status --reading deep_read。速读或局部阅读最多记 skimmed；材料不足则保留待办。

## 解释方法
按“原文位置 → 作者陈述 → 术语与公式解释 → 证据 → 对本课题的意义”组织笔记。
解释每个关键变量、下标、维度、训练与推断流程。先拆方法，再评价结果；不把摘要中的宣传性概括当作方法细节。
保留短而必要的原文摘录，主要用自己的话解释。数字、符号和引用以实际页面为准。

## 图表与公式
- 找到引用图表的原文段落，核对完整图表、图注、坐标轴、单位、图例与脚注。
- 确认比较对象、指标方向、数据集、划分、方差和适用条件，再记录变化量。
- 临时渲染与裁剪先放 .tmp/；仅把笔记实际引用、需要长期保留的清晰完整页面或裁剪存入论文目录 images/，沿用已有可靠图片，避免重复生成。
- 在笔记相关论述旁使用 images/<文件名> 的相对链接。截图须来自真实页面，不生成替代论文图。
- 扫描件、乱码或关键符号解析不可靠时使用可用的 PDF 渲染/OCR 工具；仍不清楚则标记待核对，不猜测。

## 陪读与继续
PDF 由用户在 Zotero 单独打开，精读笔记以 close-reading.md 为唯一正式文件。打开 Windows 桌面软件“精读笔记库”，按全文、作者、标签、阅读状态和研究问题查找论文笔记，并查看排版、章节目录或 Markdown 源文。页面不嵌入 PDF；证据版本和物理页码保留为原文定位依据。
软件的“编辑 MD”在双栏中写入和预览笔记。“打开 Markdown 文件”可调用系统关联的编辑器。不另写单篇 HTML、导出平行笔记或覆盖用户区块。软件阅读位置仅用于界面恢复；正式教学继续位置仍写在笔记“下一步”和 state.md。
Zotero 打开入口仅由已核对的条目/附件 key 及 library type/id 生成，不猜测所属书库；无关联时说明未配置。只读核对后可更新项目元数据，不自动导入、改写或同步 Zotero 笔记。全部统一到 Zotero 或启用 Better Notes 双向同步属于另一种维护方式，须先明确正式编辑位置与冲突处理；参见 README。页面依赖离线保存在 90_system/reader/，研究资料不上传。
沿用已有章节/段落粒度，每轮只推进一个约定单元，读完当前单元引用的必要图表再停下。
每轮保存新增实质记录；在笔记“下一步”记录精确章节、物理页码和未解决问题，state.md 只记简短继续位置。
继续时从实际笔记和对应原文页恢复，不依赖聊天记忆，不重复开始整篇阅读。

## 笔记与证据
使用项目 paper_note.md 模板，在 close-reading.md 保存问题、假设、方法、实验、结论、课题关系、证据、个人想法和下一步，不新建第二份总结。完成段落中的“待填写”应替换成有据内容；论文未报告的字段明确写“未报告”，不要填造数值。
正式笔记和研究成果不得链接 .tmp/；可复查依据必须指向归档 PDF、证据页码或已保留的 images/。清理中间文件后仍能独立恢复阅读。
证据表固定为 evidence_id、type、version、pdf_page、locator、claim、excerpt、checked_by 八列。
重要贡献、数字、公式和实验比较使用编号如 P0001:E001，记录真实 PDF 版本、从 1 开始的物理页码及章节/图表位置；type 为 author / analysis / idea；checked_by 为 ai / user；表格内竖线转义。
AI 可完成阅读，人工核对保持独立。用户原文区只保留用户实际内容。
